Newton–Raphson — inverse kinematics by iteration

Forward kinematics is a function from q to x. Inverse kinematics asks the opposite — and usually has no closed form. So we iterate: linearise with the Jacobian, take a Newton step, repeat.

No closed form

For a 6-DOF arm we can't solve "find q such that the end-effector is here" in closed form. Twelve trig equations, six unknowns, no algebraic shortcut. The pragmatic answer is iteration: start with a guess, linearise, take a Newton step toward the solution, repeat until close enough.

The forward kinematics map x = f(q) is non-linear. To invert it for a desired x*, we set up the residual r(q) = x* − f(q) and try to drive it to zero. Newton–Raphson does this by linearising at each step: replace f(q) with its first-order Taylor expansion using the Jacobian J(q), solve the resulting linear system for a step Δq, update.

The algorithm

Starting from an initial guess q0, the iteration is

  1. Compute the residual rk = x* − f(qk).
  2. Compute the Jacobian Jk = J(qk).
  3. Solve Jk Δq = rk for Δq (use pinv or a damped pseudo-inverse if J is singular).
  4. Update qk+1 = qk + αΔq, with step size α ∈ (0, 1].
  5. Repeat until ||rk|| < tolerance or max-iter reached.

The warm-start trick

When you're tracking a trajectory, every new pose is just a small step from the previous one. So use the previous solution as the initial guess for the next pose. With this single change, Newton converges in a handful of iterations instead of dozens, and you avoid jumping into a different IK branch.

The single most important practical trick: when solving IK along a continuous trajectory, use the previous waypoint's solution as the starting guess for the next. This keeps the solver on the same kinematic branch (no sudden joint flips) and converges in 2–5 iterations per waypoint typically.

Practical caveats

  • Singular configurations make the linear solve blow up. Use a damped pseudo-inverse: Δq = (JᵀJ + λ²I)⁻¹Jᵀr for some small λ.
  • Multiple solutions exist. A 6-DOF arm typically has up to 8 valid IK branches. Newton finds one — usually the one closest to the initial guess.
  • Joint limits aren't enforced by Newton itself. Clip Δq to keep q in bounds, or add a barrier term to the residual.

Quick recap

  • IK = invert FK. Closed form rarely exists for ≥6 DOF.
  • Newton–Raphson: iterate q ← q + J+(x* − f(q)). Converges quadratically near the solution.
  • Always warm-start from the previous waypoint when tracking a trajectory.
  • Use damped pseudo-inverse near singularities; clip to enforce joint limits.
