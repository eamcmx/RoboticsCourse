Lecture 09 · Module 2

Universal Robots UR5 — six revolute joints

The first six-DOF robot in the course. Reach 850 mm, payload 5 kg, all revolute. The geometry that lets a single arm reach any pose in its workspace with any orientation.

Six-DOF freedom

A SCARA can reach any point in its annular workspace, but only with the wrist pointing down. A six-DOF arm like the UR5 can reach any reachable point with any orientation. The price is more joints, more variables, and an inverse-kinematics problem we can no longer solve by inspection.

The UR5 is one of the most widely deployed collaborative robots. Six revolute joints, all with continuous rotational travel, all electrically driven. The DH parameters below come straight from the manufacturer's manual.

Play with it

Six sliders, six revolute joints. The home configuration is intentionally non-singular and away from joint limits — a good starting point. Try setting q₂ = 0 (shoulder horizontal) and watch the arm extend; that's a near-singular pose.

Reading the DH table

The UR5 uses standard DH with these parameters (metres, radians):

  joint     a         alpha     d         theta
    1     0         π/2     0.089159    q₁
    2    -0.425      0       0           q₂
    3    -0.39225    0       0           q₃
    4     0         π/2     0.10915     q₄
    5     0        -π/2     0.09465     q₅
    6     0          0      0.0823      q₆

The two long links — a₂ = −0.425 m and a₃ = −0.39225 m — are the upper arm and forearm. They sum to 81.7 cm, the nominal "reach" specification.

Forward kinematics in code

The robot definition is loaded from ROBOTS.UR5. forwardKinematics(q, robot) walks the DH chain and returns the 4×4 end-effector pose. The widget above does this on every slider change.

Quick recap

  • UR5: 6R, reach 850 mm, all-revolute. The reference robot for the rest of the course.
  • DH parameters from the UR manual; standard form. Six rows, four parameters each.
  • Forward kinematics by composing six elementary Tii−1. The widget you used does this on every slider change.
