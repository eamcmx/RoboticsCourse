Lecture 15 · Module 4

move L — straight lines in the workspace

Move the end-effector along a straight 3D path between two poses. Discretise the path, solve IK at every via-point with a warm-start, animate. We build it from scratch so it stops being magic.

When the path matters

Welding, gluing, cutting, drawing — anything where the work piece sees the end-effector's trajectory — requires move L. Pick two poses, ask for a straight line between them, and the controller finds the joint values at every step. The internals are exactly what you built in Lecture 12.

To follow a straight line in 3D, we discretise the line into via-points and solve IK at each. The previous waypoint's solution is the warm-start for the next — Lecture 12's setup applied repeatedly.

The algorithm

Given start pose T0 and goal pose T1 as 4×4 matrices, with N via-points:

  1. Interpolate position linearly: p(s) = (1−s)·p0 + s·p1.
  2. Interpolate orientation via SLERP (or for small rotations, linearly interpolate the rotation matrices and re-orthogonalise).
  3. For each s ∈ {0, 1/N, 2/N, …, 1}, solve IK for the corresponding T(s), warm-started from the previous q.
  4. Send the resulting q sequence to the motors at the controller's update rate.

Time parameterisation

The waypoint sequence above is purely geometric — it doesn't say when the robot reaches each one. To turn the path into a trajectory, you assign a time profile s(t) ∈ [0, 1]. Common choices:

  • Linear in t — constant speed along the path.
  • Trapezoidal velocity — accelerate, cruise, decelerate. Smooth at the endpoints, easy on the motors.
  • S-curve — same with continuous acceleration. Smoother still; standard for high-precision tasks.

The choice doesn't affect the path shape, only the velocity profile along it.

Quick recap

  • move L = discretise the task-space line + IK at every via-point + warm-start chaining.
  • Position: linear interpolation. Orientation: SLERP.
  • Time profile (linear/trapezoidal/S-curve) is a separate concern from the geometric path.

Build move L from scratch

  1. Implement moveL(T_start, T_goal, N, ik_fn). Use SLERP for orientation interpolation.
  2. Apply it to the SCARA Cobra to draw a 0.2-m horizontal square in the x–y plane at z = 0.3.
