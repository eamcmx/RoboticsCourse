Lecture 10 · Module 2

The Denavit–Hartenberg convention

A coordination standard between humans. Four parameters per joint and a strict procedure to assign frames so any two engineers describing the same robot get the same matrices.

Why a convention?

Up to here you've written FK by composing transforms in whatever order made sense to you. That's fine for solo work but it doesn't scale: when you read a paper or a manual, you need to know which frames the author chose, which axis points where, and which rotation is positive. The DH convention is a set of rules that pins all of this down.

The Denavit–Hartenberg convention is a procedural recipe: given a serial chain of joints, it tells you exactly where to put each frame and which direction each axis points. Following the recipe gives you a table of four numbers per joint — a, α, d, θ — that fully describes the geometry.

The four rules

  1. Z-axis along joint axis. zi is aligned with the axis of joint i+1 — the axis the joint either rotates around (revolute) or translates along (prismatic).
  2. X-axis along common normal. xi is the common perpendicular between zi−1 and zi, pointing from zi−1 to zi. If the two z's intersect, xi = zi−1 × zi.
  3. Origin at the intersection. Origin of frame i lies at the intersection of xi and zi.
  4. Y-axis by right-hand rule. yi = zi × xi.
The four parameters fall out automatically

Once frames are placed by these rules, the four DH parameters describe the relationship between consecutive frames: ai is the link length along xi; αi is the link twist around xi; di is the link offset along zi−1; θi is the joint angle around zi−1. For a revolute joint, θ is variable. For prismatic, d is variable.

Same robot, two valid frame choices

The convention is strict but not unique — there are still some choices to make (e.g., the direction of x0 when there's no z−1). Two engineers can produce different DH tables for the same robot if they make different but valid choices. The end-effector pose is identical; the intermediate frames differ.

Quick recap

  • Four rules to assign frames; four parameters per joint to describe transitions.
  • Each row of a DH table contributes a single elementary 4×4 transform; FK is their product.
  • The convention is a coordination standard: it lets two engineers describe the same robot with the same numbers.
  • Two valid DH tables can describe the same robot — only the end-effector matrix is invariant.
